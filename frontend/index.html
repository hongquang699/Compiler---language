 Câu hỏi thường gặp (FAQ)

                        
Giải đáp các thắc mắc phổ biến về môi trường và AI của Local CP Studio.

                    

                


                

                    

                        
                        

                            Local CP IDE là studio lập trình thuật toán chạy trực tiếp trên máy cục bộ của bạn hoặc máy chủ riêng tư. Tích hợp sẵn Monaco Editor chuẩn VS Code, trình biên dịch Sandbox siêu tốc (C++, Python, Rust, Java), và đặc biệt là AI Agent tự sửa lỗi thông minh mà không phụ thuộc vào internet công cộng.
                        

                    

                    

                        
                        

                            AI Agent hoạt động qua 5 bước: Tra cứu thuật toán (RAG) → Lập kế hoạch (Plan) → Sinh mã nguồn → Chạy sandbox kiểm thử → Tự sửa code nếu có lỗi (Auto-fix). Khi bạn tham gia Cuộc thi (Contest), hệ thống bảo mật sẽ tự động khóa AI để đảm bảo tính công bằng 100%.
                        

                    

                    

                        
                        

                            Hệ thống hỗ trợ toàn diện các ngôn ngữ thi đấu phổ biến nhất: C++17 (g++ O2), Python 3.12, Java 17 (OpenJDK), C11, Rust 2021 và Go 1.21 với cờ tối ưu hóa tốc độ cao.
                        

                    

                    

                        
                        

                            Có. Chúng tôi tuân thủ chính sách Local-First. Code của bạn được lưu trong cơ sở dữ liệu SQLite cục bộ mã hóa, phiên làm việc được xác thực bằng JWT an toàn, không bị gửi cho bên thứ ba.
                        

                    

                    

                        
                        

                            Tài khoản Quản trị viên (Admin) có thể vào tab Admin để tạo cuộc thi mới, cấu hình thời gian thi, hoặc dùng tính năng "Nạp problem ClueOJ" trực tiếp từ thư mục đề bài chuẩn của bạn.
